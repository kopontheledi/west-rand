# Westrand Private School Website

Responsive React + Vite website using JavaScript, React Router, Lucide icons and Tailwind CSS v3.

## Pages
- Home
- About Us
- Admissions
- Curriculum
- Extracurricular Activities
- Gallery
- Contact Us

## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Open the integrated terminal and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite, normally http://localhost:5173.

Build for deployment:

```bash
npm run build
```

The production site is generated in `dist`.

## Before publishing
- Confirm all official school information, including school history, vision, mission, curriculum/examination body, subjects, grades, extracurricular offerings, fees, application requirements and office hours.
- Replace the sample Unsplash images with school-approved photographs.
- The admissions form opens the visitor's email application with a pre-filled message. It does not store submissions or send email through a backend.
- Confirm the exact Google Maps pin and update the directions URL if necessary.
- Obtain parent/guardian consent before publishing identifiable learner photographs.
- Configure SPA fallback/rewrites on your hosting provider so direct page URLs load correctly.
